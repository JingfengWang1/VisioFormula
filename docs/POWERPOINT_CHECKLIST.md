版本：0.10.0-preview.1；日期：2026-11-17。

本版保留 Visio 功能，新增 PowerPoint 的直接拖放、复制、源码保存、读回和手动原位更新。PowerPoint 自动更新与批量样式暂不启用，等本清单验收后再继续。

代码和 COM 接口检查已经执行；下列鼠标操作、撤销/重做和视觉项目由你实际验证，当前均为“待验证”。没有使用 computer use。

## 准备

1. 正常退出旧版工具，双击桌面的“Visio Formula”。窗口标题应包含 **0.10.0** 和“PowerPoint 原型”。
2. 打开 Windows 桌面 PowerPoint，新建一个空白测试演示文稿并添加空白幻灯片。
3. 在工具顶部的目标下拉框选择 **PowerPoint**。复制按钮和拖动提示都应切换到 PowerPoint。
4. 选择 Times / NewTX 字体、18 pt，粘贴下面的源码 A，等待精确结果。

源码 A：

```latex
G(s)=\frac{1}{s^2+2\zeta\omega_n s+\omega_n^2}\quad\text{AbC}
```

源码 B：

```latex
G(s)=\frac{\alpha+\Gamma}{(s+1)(s+2)}
```

源码 C（矩阵、多行对齐）：

```latex
\begin{aligned}\mathbf{v}&=\begin{bmatrix}v_d\\v_q\end{bmatrix}\\\omega_0&=\hat{\omega}_s+\Delta\omega_s\end{aligned}
```

## 本原型的边界

- PowerPoint 拖放通过原生复制数据实现，**会把公式放入系统剪贴板**；取消拖动也可能留下这份复制内容。Visio 原有拖放实现保持不变。
- PowerPoint 只支持手动原位更新，批量菜单在 PowerPoint 模式下不可用。设置中的自动更新仍仅适用于 Visio。
- 先验证独立公式图形。组合内部的公式、取消组合后的内容，以及转换成其他图形后的内容不在本原型支持范围内。
- 切换输出目标会解除旧关联；修改文档内公式前需要重新读回。请让目标选项与接收软件一致。
- 尚未验证多个独立 PowerPoint 进程、PowerPoint 网页版或 macOS。源码与 SVG 随 `.pptx` 保存，不依赖原电脑缓存。
- 需要你实际确认 P1–P7 后，才把核心流程视为通过；本清单不是已通过报告。
