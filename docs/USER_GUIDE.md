# Visio Formula 0.10.0-preview.1 使用说明

将 TeX 公式以矢量图直接拖入 Visio，支持七种数学字体。

## 启动与升级

解压整个文件夹，运行 `VisioFormula.exe`。保留旁边的 `VisioFormula.exe.config` 和完整 `assets` 文件夹。运行环境为 Windows x64、.NET Framework 4.8 和桌面版 Visio；本机 TeX 字体还需要 LaTeX 与 dvisvgm。

从旧版升级时先正常关闭旧程序，再启动新版。字体、字号、快捷输入和草稿继续从 `%LOCALAPPDATA%\VisioFormula` 读取，不需要手动复制到程序目录。新缓存也位于此用户目录下，不进入同步的程序文件夹。

## PowerPoint 原型

在主窗口顶部选择 PowerPoint，再拖动或复制精确结果到幻灯片。选中独立公式后，点“编辑选中公式”，修改源码并等待精确结果，点“原位更新”。使用步骤和待验收项目见 [PowerPoint 验证清单](https://github.com/JingfengWang1/VisioFormula/blob/main/docs/POWERPOINT_CHECKLIST.md)。

PowerPoint 原型拖放会占用系统剪贴板；自动更新、批量样式和组合内公式暂不支持。切回 Visio 后，原有功能继续可用。目标选择会被记住；切换目标会解除旧公式关联。

下文的自动原位更新与批量样式仍指 Visio 功能。

## 菜单与设置

“更多”只保留设置、恢复最近草稿、批量统一公式样式三个入口。

进入设置后，可调整自动原位更新，并打开快捷输入、环境检查、缓存管理。配置功能统一从这里进入。

## 新电脑环境检查

打开“更多 → 设置 → 环境检查”。快速检查显示 Visio、TeX 工具路径及版本、离线预览资源和存储状态。

点击“测试渲染”，实际检查全部七种数学字体；某个字体失败不会阻止其余字体继续测试。缺少本机 TeX 时，可以先选择 MathJax / TeX 字体使用。

如果没有找到 TeX，点击“选择 TeX 路径”，选择同时包含 `latex.exe` 和 `dvisvgm.exe` 的目录。关闭检查窗口后保存该设置；“恢复自动查找”可清除手动路径。已有 `tex-bin.txt` 继续兼容。

“复制诊断信息”用于排查问题，内容包含本机路径；请按需要选择分享范围。工具提供修复提示，不自动安装 TeX 或宏包。

## 自动原位更新

1. 在 Visio 中选中一个本工具生成的完整公式组。
2. 在工具中点击“编辑选中公式”，读回源码。
3. 打开“更多 → 设置”，勾选“自动更新已关联的 Visio 公式”，点击保存。开关默认关闭，之后会记住设置。
4. 修改源码、字体或字号。停止输入约 600 ms 且精确渲染成功后，自动更新对应的 Visio 公式。

自动更新固定关联读回的目标，不会因为你在 Visio 点选别的形状而转移。状态提示可查看文档、页面和公式信息。

输入不完整或编译错误时，Visio 保留上次成功的公式。每次实际同步支持一次 Visio 撤销；检测到目标被修改、移动、缩放或撤销后，会暂停同步。重新读回公式，或者明确点击“原位更新”，可以继续。

新建、恢复草稿或目标消失会解除关联。重开工具后，即使开关仍然开启，也必须重新读回目标。Visio 文档仍需要你自行保存。

## 缓存管理

打开“更多 → 设置 → 缓存管理”。默认自动清理开启，容量目标 **20 MB**、保留 **7 天**，可自行调整。

“立即清理”只删除可以释放的编译缓存，显示实际释放大小。当前预览、会话缓存、编译、拖放、批量操作及其他窗口正在使用的结果会保留，因此占用可能暂时高于容量目标。

勾选“包含此程序旁的旧版缓存”后，也可以清理当前程序目录下已识别的旧编译文件。未知文件、目录链接、只读或被占用的缓存会跳过。

草稿、快捷输入、个人设置、导出的 SVG 和 Visio 文档不属于缓存清理范围。清理后再次使用旧公式可能需要重新编译。
